# Supply Chain Performance Analysis

## Overview

This project is a **Data Analytics case study on Supply Chain Performance** using the **DataCo Global Supply Chain Dataset**.

The main goal of this project is to understand **delivery delays, shipping performance, customer profitability, and regional shipping patterns** using Python and statistical analysis.

### What I worked on

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Delivery and shipping analysis
- Customer segment analysis
- Regional analysis
- Statistical hypothesis testing
- Business insights and recommendations

### Statistical Tests Used

- Chi-Square Test
- One-Way ANOVA

### Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook / Google Colab

### Key Focus

The project mainly focuses on identifying **late-delivery problems**, understanding the factors related to shipping performance, and finding useful business insights from the data.

**Dataset:** DataCo Global Supply Chain Dataset  
**Records:** 180,519  
**Project Type:** Data Analytics / Statistical Analysis
