# Supply Chain Performance Analysis

## Overview

This project is a **Data Analytics case study on Supply Chain Performance** using the **DataCo Global Supply Chain Dataset**.

The main goal of this project is to understand **delivery delays, shipping performance, customer sales, profitability, and regional shipping patterns** using Python and statistical analysis.

The dataset contains company order data from **2015-01-01 to 2018-12-01**.

### What I Worked On

- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Delivery and shipping analysis
- Customer segment analysis
- Regional analysis
- Statistical hypothesis testing
- Business insights and recommendations

### Statistical Tests Used

- Chi-Square Test
- One-Way ANOVA

### Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook / Google Colab

## Key Visualizations

### 1. Delivery Status Distribution

The pie chart shows the percentage of orders based on their delivery status.

- **Late delivery:** 54.7%
- **Advance shipping:** 31.2%
- **Shipping on time:** 7.2%
- **Shipping cancelled:** 4.3%
- **Order cancelled:** 2.7%

This shows that **late delivery is the major delivery issue** in the dataset.

### 2. Sales per Customer

The distribution shows that **most customers have sales between $0 and $500**.

There are comparatively fewer customers with very high sales values.

### 3. Total Profit by Top 5 Departments

The analysis shows that **Fan Shop generates the highest total profit**, followed by **Apparel**. The remaining departments have comparatively lower total profit.

## Key Focus

The project mainly focuses on identifying **late-delivery problems**, understanding shipping performance, analyzing customer sales and profitability, and finding useful business insights from the data.

**Dataset:** DataCo Global Supply Chain Dataset  
**Records:** 180,519  
**Time Period:** 2015-01-01 to 2018-12-01
